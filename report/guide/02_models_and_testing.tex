\section{How we tested}

\begin{plainwords}
Every model drove the \emph{same 200 scenarios} that nobody had used for training or for choosing models. A drive counts as a success only if it reaches the destination without a collision and without leaving the road. Because every model drives the same scenarios, two models can be compared on the drives where they differ, which detects a difference of 7.5 percentage points with 200 drives.
\end{plainwords}
\begin{itemize}
\item \textbf{Simulator and scenarios.} MetaDrive 0.4.3; a scenario seed fixes the road, route and traffic; traffic is sparse (density 0.05) for all main results and dense (0.2) only for diagnostics; 800 steps of 0.1 s = 80 s per drive.
\item \textbf{Separate scenario blocks:} training seeds 2000--2999; validation seeds 3100--3139 (to choose models); test seeds 1010--1049 (40 drives, pilot) and 5000--5199 (200 drives, the main test).
\item \textbf{Four ways a drive ends:} success, collision, left the road, timeout.
\item \textbf{Statistics:} 95\% Wilson confidence intervals; exact McNemar test and bootstrap interval for paired differences.
\item \textbf{What the drivers see during the tests.} The full camera pipeline costs about two seconds per step, so the drivers were tested in a \emph{camera-free surrogate}: the grid is built from the simulator's list of vehicles (an ideal detector), then degraded by the measured weather effect where weather is studied. This departs from a rule written in the GitHub README (Section~\ref{sec:g-github}); results are valid for the driving models, not for the camera system as a whole.
\end{itemize}
