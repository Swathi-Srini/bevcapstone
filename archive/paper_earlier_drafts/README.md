# Paper folder (everything for the write-up in one place)

- `ARCHITECTURE_CHANGES.md` - each change to the original architecture, with evidence and status.
- `figures/` - generated by `make_figures.py` from real result files (never hand-edited). Fig 1 architecture, 2 detector retention, 3 earlier policies, 4 DAgger validation, 5 caution results (appears when evals finish), 6 caution vs control training.
- `literature/` - `LITERATURE_REVIEW.md` (living review with verification levels) and `references.bib` (verification level in each `note`).
- `PAPER_OUTLINE.md` - research question, sub-questions, contributions, section plan, status tracker.
- `results/` - copies of the JSON result files the figures use.

Regenerate: `venv/Scripts/python.exe paper/make_figures.py` (from the repo root).
