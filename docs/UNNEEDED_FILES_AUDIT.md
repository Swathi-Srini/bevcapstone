# Audit: files that are not needed (14 November 2026) - NOTHING IS DELETED

**Definition used.** A file is "needed" if it is required to (a) run the current base-model training and evaluation, (b) reproduce a number in any report or README, (c) build the reports, (d) hand the reinforcement-learning part to the teammate, or (e) it belongs to a teammate's module. A file that is none of these is a *candidate*. Candidates are only ever **archived, ignored or left in place**; deletion is not proposed. Sizes were measured on the maintainer's working copy (read-only scan, 14 Nov 2026); the status of every script is in `docs/STATUS_INDEX.md`.

## Notes on method

* `report/` is 954 MB; 943 MB of it is categories 3 and 4. The tracked part of `report/` is about 40 files.
* Everything above is covered by the 14 Nov dated backup (`docs/BACKUP_STRATEGY.md`), so any later archiving can be undone.
